# Pitch (manual 30.5)

**Family:** note transformation
**Note status:** dump checked, partly measured (MIDI recordings, [Measured](#measured))

## Summary

Transposes every note that passes through by a fixed amount: up to 128 semitones either way, or,
since Live 12.0, up to 30 scale degrees of the clip's scale. A pitch window set by Lowest and
Range decides which notes are allowed through, and a Mode chooser decides what happens to those
outside it: they are blocked, folded back into the window or pushed to its nearest edge. Step
Up and Step Down buttons move the transposition by a set width, so a note or a controller
button can change key in jumps. Used for key changes, octave doubling (in a Rack), limiting a
player to a register and live transposition [manual].

History: Live 11 had Pitch, Lowest and Range with one behaviour: notes outside the window were
blocked, the window being tested on the *untransposed* pitch, before transposition [source: 3].
Live 11.2.10 slightly updated the UI [source: 4]. Live 12.0 added Use Current Scale, the Step
Down / Step Up buttons with Step Width, the Mode chooser (Block, Fold, Limit), moved Lowest and
Range, and made per-note pitch bend follow the scale [source: 2]. 12.0.5 made the Pitch control
less sensitive to the mouse and fixed the device's width regardless of control-surface lock;
12.1.10 fixed per-note pitch bend for out-of-scale incoming notes with scale awareness on
[source: 2].

## MIDI flow

Shared parts (title bar, Use Current Scale and how the clip's scale is chosen, note-off and MPE
handling, racks, latency): [common.md](common.md).

```text
incoming note-on (p, v)
   │
   ▼
 Use Current Scale on and a clip scale: p moved to the nearest scale note (a tie goes down) [measured 12.4.6]
   │
   ▼
 Block only: range test on p vs [Lowest, Lowest + Range]   [measured 12.4.6: on the input pitch]
   │ inside ─► on          outside ─► note dropped (the LED flashes [manual])
   ▼
 transposition by Pitch (semitones or scale degrees)  p' = p + Pitch
   ▼
 Fold / Limit only: p' brought into [Lowest, Lowest + Range]   [measured 12.4.6: on the output pitch]
   ▼
 clamp to 0..127 [measured 12.4.6] ─► note-on (p', v)
incoming note-off ─► note-off for the same output pitch the note-on produced [measured 12.4.6]
other messages ─► pass through; per-note pitch bend of MPE notes is re-mapped when scale awareness is on
```

The order of the range test and the transposition differs by mode [measured 12.4.6]: Block tests
the pitch *before* the transposition, as the Live 11 manual says [source: 3], while Fold and Limit
bring the pitch *after* the transposition into the window, so their output always lies inside it.

## Behaviour

**Transposition.** `p' = p + Pitch` in semitones for Pitch measured in st, clamped to 0 – 127:
Pitch +12 sends input 116 – 127 all to 127, Pitch −12 sends 0 – 12 all to 0, and Pitch +127, +128 or
−128 sends every input to 127 or 0, as the knob's ends do [measured 12.4.6]. No note is lost to the clamp: several inputs can land on one
pitch. Pitch is an integer; there is no fine tuning and no cents (the device does not send pitch
bend) [inferred]. With Use Current Scale on and a scale on the clip, `Pitch Scale Degrees` counts
steps along the scale's notes of any octave: in C major +1 takes C to D, E to F and B to C (+2, +1,
+1 st), +7 is an octave, −1 takes C to B below. A pentatonic scale counts five notes to the octave
(C minor pentatonic: +5 is an octave; +1 takes C to E♭, G to B♭, B♭ to C) [measured 12.4.6]. A
note that is not in the scale is first moved to the nearest scale note, a tie going down, and then
counted from there. At 0 degrees in C major C♯ plays as C, D♯ as D, F♯ as F, G♯ as G and A♯ as A.
In C minor pentatonic at +1, D (nearer E♭ than C) goes to F as E♭ would, and E (a tie between E♭
and F) goes to F as E♭ would [measured 12.4.6]. The scale's root does not matter, only its set of notes (D Dorian
and C major give the same maps) [measured 12.4.6]. With Use Current Scale on but no scale on the clip,
`Pitch Scale Degrees` counts semitones [measured 12.4.6].

**Range test and Block.** Lowest and Range define the pitch window `[Lowest, Lowest + Range]`
through which notes may pass [manual]. Notes outside are "blocked": no note-on is sent and the
LED next to Range flashes [manual]. Block tests the pitch *before* the transposition: with
Lowest C3 (60), Range 12 and Pitch +24, the inputs 60 – 72 pass and sound 84 – 96, and nothing else
does. Both ends are included, so the window holds Range + 1 pitches; Range 0 passes only Lowest
[measured 12.4.6]. With Use Current Scale on, Lowest and Range are still MIDI notes and semitones
(Lowest 62, Range 5 passes the inputs 62 – 67), the test is made on the input as played, and a
passing note outside the scale is then moved to the scale as above (63 plays as 62) [measured 12.4.6].

**Fold.** Notes are wrapped into the window with a period of Range + 1: after the transposition,
`p'' = Lowest + ((p' − Lowest) mod (Range + 1))`. For Lowest 60 and Range 11 every pitch lands
in 60 – 71 with the same pitch class (input 0 plays 60, 12 plays 60, 13 plays 61, 71 plays 71, 72
plays 60); for Range 7 the period is 8: input 0 plays 64, 4 plays 60, 8 plays 64, 12 plays 60 and 127
plays 63; Range 12 has period 13 and Range 24 period 25. Range 0 sends every note to Lowest. It is
a wrap, not a mirror, and not a shift by octaves [measured 12.4.6]. Notes inside the window are
unchanged.

**Limit.** After the transposition, `p'' = min(max(p', Lowest), Lowest + Range)`: notes below the
window are raised to its lowest note and notes above are lowered to its highest, for
Range 7, 11, 12 and 24; Range 0 sends every note to Lowest [measured 12.4.6].

**Whether Fold and Limit act before or after the transposition.** After. With Lowest 60, Range 11
and Pitch +5, input 0 plays 65 (0 + 5 wrapped) but input 7 plays 60 (7 + 5 = 12 wrapped), where
folding first would have given 72; with Limit and Pitch +5 the inputs up to 55 play 60 and 56 plays
61, and with Pitch +12 the inputs up to 48 play 60 [measured 12.4.6]. So in Fold and Limit the
output is always inside the window, while in Block it is not (the window is on the input). Fold
with Pitch +12 and Range 11 gives the same notes as Pitch 0, as the period is 12.

**Out-of-range output.** `p'` below 0 or above 127 is clamped to 0 or 127, not dropped
[measured 12.4.6].

**Step Up / Step Down.** A press changes `Pitch` by ±Step Width, clipped at ±128 st or ±30
degrees (the two Pitch parameters' ranges [dump 12.4.6]) [inferred]. They are momentary buttons and the whole set is mappable [manual]. A press
while notes are held does not change the sounding notes (their note-offs are matched), only
later notes [inferred; measure] (the held-note rule is measured for automated Pitch: see
Note-offs). Step Width is 1 – 48 st or 1 – 30 degrees [manual; dump 12.4.6];
these are two separate parameters, and Use Current Scale chooses which one applies
[dump 12.4.6; inferred].

**Note-offs.** Each output note ends with the length of its input note and at the pitch it
started with. A Pitch step from 0 to +5 (automation) at beat 2 of a 4-beat held C3, with a held chord
alongside, left the notes as they were: C3 sounded 60 for 4 beats, with no extra, early or hanging
note [measured 12.4.6]. Switching the device off at beat 4 and on again at beat 6 under a held chord
at Pitch +12 changed nothing: all four notes sounded +12 for their whole length, with no cut
and no re-trigger, so the note-offs are not affected by the device's own switch (common.md case C1;
a note starting while the device is off was not tried) [measured 12.4.6]. The note-off of a
blocked note was not observed apart from the absence of its note.

**Scale-aware per-note pitch bend.** With Use Current Scale on, the pitch bend of an incoming MPE
note is re-mapped so a bent note stays in the scale; 12.1.10 fixed this for notes that were not in
the scale [manual; source: 2]. The re-mapping law is [measure]. Without scale awareness per-note
pitch bend passes through unchanged [inferred].

**Velocity, release velocity and other messages** pass through unchanged: velocity, start and
length of every note were equal to the input's in all the recorded cases [measured 12.4.6; release
velocity was not read]. Pitch has no timing and no latency: every output note starts at its input
note's start, to within the recording's resolution [measured 12.4.6].

## Edge cases

[measured 12.4.6] where tagged; the rest [measure].

- **Pitch 0, Lowest 0, Range 127:** pass-through [measured 12.4.6]. Pitch 0 with any window: the
  device is a pure range filter (Block) [measured 12.4.6].
- **Output beyond 0 or 127** (note 120 with +24): clamped [measured 12.4.6].
- **Range 0:** one-note window; Block passes only that pitch; Fold and Limit send everything to
  it [measured 12.4.6].
- **Lowest + Range > 127:** not tried.
- **Pitch automated while a note is held:** the note-off goes to the original output pitch, no
  hanging note [measured 12.4.6]. Step presses were not tried (buttons, not parameters).
- **Lowest/Range/Mode changed while a note is held:** not tried.
- **Use Current Scale toggled while Pitch is large** (say +100 st then degrees): the stored value
  is clipped or kept. Not tried; the dump says they are separate parameters.
- **No scale on the clip** with Use Current Scale on: degrees count semitones [measured 12.4.6]. A
  tuning system loaded: not tried (common.md).
- **Incoming note not in the scale** with a degree shift: moved to the nearest scale note first
  [measured 12.4.6].
- **Velocity 0 note-on, velocity 127:** not tried.
- **Device off with notes held:** held notes are unaffected [measured 12.4.6] (see Note-offs).
- **Drum Rack chain:** the transposition applies after the pad's Receive note matched
  (common.md).

## Measurement plan

Observation: record the device's output on a second MIDI track and read the notes back
([common.md](common.md) › Measurement plan shared by the MIDI effects; arming and recording are the
user's step). The shared cases C1, C4 (scale degrees), C5 (MPE) and C6 (Rack) apply. A sine
instrument after the device is a sufficient fallback for pitch-only checks.

Input clips (120 bpm; each note 1 beat, velocity 100, one note per beat):

- **A.** Every pitch from 0 to 127 in turn (128 notes, 128 beats, 32 bars in 4/4). Used for
  the window maps.
- **B.** C3 to C4 chromatic (13 notes) with the clip's scale set to C major (and again with
  D Dorian, C minor pentatonic, and with the scale off).
- **C.** Held C3 with the Pitch value changed by clip automation mid-note.

1. **Parameter facts.** Done: the Live 12.4.6 parameter dump and saved set (Controls, `.als`
   import). Semitones and degrees are separate parameters, so nothing clips when Use Current
   Scale is toggled.
2. **Transposition.** Clip A with Pitch = 0, +1, +12, −12, +127, −128 and +128, Lowest 0, Range
   127: output pitch per input pitch, and which notes are lost at the ends.
3. **Range test: block.** Clip A with Lowest = C3 (60), Range = 12, Pitch = 0: pass band and
   inclusive edges. Then Pitch = +24: does the window follow the input or output? Read the
   passing input pitches.
4. **Fold.** Clip A with Lowest = 60, Range = 11, then 7, 12, 0 and 24, Pitch = 0: output
   pitch for each input (the fold law) and then with Pitch = +5, +12 to see the order of fold
   and transposition.
5. **Limit.** The same maps with Limit, including Range = 0.
6. **LED.** Observe in Live's window with the user: whether the LED flashes in Fold and Limit
   (cannot be read through the API).
7. **Steps.** Step Width at 1, 7, 48; press Step Up / Down through `set_device_parameter`
   (the buttons may be API parameters) from Pitch 120 and −120: the clip. Check the Step Width
   limits with Use Current Scale on.
8. **Scale degrees.** Clip B with C major, Pitch = +1, +2, +7 (an octave), −1; the same with D
   Dorian and C minor pentatonic (5 notes per octave), and with scale off (Use Current Scale on).
   Include the notes not in the scale (C#3): rounding of the starting degree. Compare against
   C4 in all cases of 7 notes. Lowest and Range with Use Current Scale on: semitones or degrees?
9. **Note-offs.** Clip C, with the Pitch automation: read the pitch of the note-off against the
   note-on.
10. **MPE.** A clip with per-note pitch bend at ±2 semitones on an in-scale note and an out-of-
    scale note, Use Current Scale on (common.md C5).
11. **Latency.** C2.

## Measured

Recorded from Live 12.4.6: each case is a MIDI track with the device and a second track that
records its output (`devices/30.05-pitch/results/*.json`, plan steps 2 – 5, 8, 9 and the
latency of 11; input clips as in the plan, the notes a half beat apart). All the laws are in
Behaviour and Edge cases; in short [measured 12.4.6]:

- Transposition: add Pitch, clamp to 0 – 127 (nothing is dropped).
- Block: window on the input, `[Lowest, Lowest + Range]` inclusive, then transposed.
- Fold: transposed, then wrapped with period Range + 1. Limit: transposed, then clamped.
- Scale degrees: not-in-scale notes go to the nearest scale note (ties down), then count
  degrees; only the set of notes matters. Lowest and Range stay in semitones.
- Start, length and velocity unchanged; no latency.

Not measured: the LED (step 6), Step Up / Step Down (step 7), MPE pitch bend (step 10), a note
that starts while the device is switched off, and Lowest + Range above 127.

## Implementation notes

- Stateless apart from a held-note table (input (channel, pitch) → output pitch) that makes the
  note-off match. Integer arithmetic only; no audio.
- Keep three code paths for the three modes; in Block the range test goes before the transposition;
  in Fold and Limit the window is applied to the transposed pitch (both measured), then clamp
  to 0 – 127. Fold is a plain modulo with period Range + 1.
- Scale mode needs the clip-scale service (common.md): snap the pitch to the nearest scale note
  (a tie goes down), take its degree index, add the offset, map back (the measured rule).
- Parameter units: Pitch and Step Width each have a semitone and a degrees parameter, and Use
  Current Scale chooses between them; the import keeps all four numbers and the flag.
- **`.als` import.** The device element is `MidiPitcher` [als 12.4.6]. Parameter elements, in
  stored order, all as the API shows them [als 12.4.6]: `On`, `Pitch` (semitones, −128 – 128),
  `PitchScaleDegrees` (−30 – 30), `Lowest` (MIDI note, 0 – 127), `Range` (0 – 127), `RangeMode`
  (Mode, index 0 – 2: Block, Fold, Limit), `UseCurrentScale` (bool), `StepWidth` (1 – 48),
  `StepWidthScaleDegrees` (1 – 30). Not parameters, also stored: six view-scroll positions
  (`PitchScrollPosArranger`, `…Envelope`, and the same for the degree Pitch and for Lowest).
