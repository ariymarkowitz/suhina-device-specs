# Filter Delay (manual 29.19)

**Family:** delay and looping
**Note status:** dump checked, partly measured (top100 and remaining runs, [Measured](#measured))

## Summary

Three delay lines, each fed through its own pair of linked low-pass and high-pass filters (a
movable band), so that only part of the spectrum is delayed. The feedback of each line also runs
back through its filter. Typical uses are rhythmic band-limited echoes, stereo spreads where each
band echoes at a different time, and, with short times, simple room simulations [manual, source: 2].

## Signal flow

```text
in L ──► [band filter 1 (HP+LP)] ──► delay 1 ──► Volume 1 ──► Pan 1 (default: left)  ─┐
in L+R ─► [band filter 2 (HP+LP)] ──► delay 2 ──► Volume 2 ──► Pan 2 (default: both)   ├─► (+) ─► out
in R ──► [band filter 3 (HP+LP)] ──► delay 3 ──► Volume 3 ──► Pan 3 (default: right)  ─┘
              ▲                          │
              └── Feedback (per line) ◄──┘     (feedback re-enters before the filter) [manual]
in (dry) ──► Dry level ──────────────────────────────────────────────────────────────► (+)
```

- Delay 1 takes the input's left channel, delay 2 takes left and right together (a mono sum
  [source: 2]), delay 3 takes the right channel; each output goes back to the channel its input
  came from unless the Pan controls move it [manual].
- Each line has its own On switch, filter On switch, time, feedback, pan and volume
  [manual, source: 2].
- The feedback of each delay is routed back through that delay's filters [manual], confirmed: each
  repeat is filtered once more than the one before [measured 12.4.6] (Measured › Feedback). The
  feedback also inverts the polarity of every repeat and adds one sample of delay per pass
  [measured 12.4.6] (Measured › Feedback).

## Behaviour

- **Time.** Synced time = button × one sixteenth note = `15000 / BPM` ms per button step; at 150 BPM
  button "2" is 200 ms [source: 2]. The percentage field scales the whole delay (+33.3 % on 200 ms
  gives 266.6 ms; −33.3 % and +33.3 % on "4" produce triplet and shifted-triplet spacing)
  [source: 2]; measured: 500 ms x (1 + swing), 666.50 ms and 333.50 ms at ±33.3 %
  [measured 12.4.6] (Measured › Time). Buttons 3 and 6 are dotted-eighth and dotted-quarter delays [source: 2]. Free
  time: 1 – 300 ms on the legacy device [source: 2], which includes the short times (about 1 –
  25 ms) used for room simulation with little feedback [source: 2].
- **Filters.** The low-pass and high-pass are linked: the X-Y pad sets a centre frequency
  and a bandwidth, the two cutoffs sit either side of the centre [manual, inferred]. This is
  equivalent to a band-pass with Q set by Width, and the filter is before the delay line
  [manual]. Measured: a 2nd-order Butterworth high-pass (12 dB per octave) at Freq / 2^(Width/2)
  followed by a 2nd-order Butterworth low-pass at Freq x 2^(Width/2), each corner held to 50 Hz –
  18 kHz, so Width is the distance in octaves between the -3 dB corners; the response matches Delay's
  filter to 0.02 dB [measured 12.4.6] (Measured › Filter).
- **Feedback.** Each delay's feedback goes back through that delay's filters, so every repeat is
  filtered again and the band narrows with repeats [manual]. The loop can oscillate when feedback
  is very high [manual]; at the 100 % maximum the repeats of an impulse neither grow nor fade at low frequencies
  (their signed sum stays 1.000 for 19 repeats) and the highs slowly die [measured 12.4.6]
  (Measured › Feedback). No limiting was seen.
- **Routing.** Delay 2 takes the sum of the two channels; with default Pan its output goes
  to both [manual]. The Pan controls then place each delay anywhere in the stereo field [manual].
- **Volume.** Post-delay gain up to +6 dB per line [manual].
- **Dry.** Dry level control instead of a Dry/Wet knob: the device is a mixing structure with
  separate dry and three wet levels [manual].
- **Latency.** None reported [inferred].

## Edge cases

- All three delays off: only the dry signal remains [inferred].
- Filter widest or off: the line passes the full spectrum [source: 2].
- Delay time changes while playing: whether the pitch glides (like the legacy devices,
  which repitch) or crossfade is [measure]; the legacy Simple Delay changed pitch when its time
  was turned [inferred].
- Feedback high with sync times and the filter wide open: unbounded growth [manual]. At the 100 %
  maximum with the filter off an impulse does not grow in 19 repeats (the sum of each repeat stays
  1.000); growth with a longer-lasting signal was not tested [measured 12.4.6].
- Mono input: delays 1 and 3 receive the same signal as 2 [inferred].
- Tempo change with Sync on: delay time changes continuously [inferred].
- Pan fully hard: the delay appears on one side only [manual].
- Very short delay (1 ms) with feedback: comb resonance [source: 2].

## Measured

[measured 12.4.6] Behaviour runs at 44.1 kHz in Live 12.4.6 (`measurements/29.19-filter-delay/`:
`filter-delay-time`, `filter-delay-sync`, `filter-delay-filter`, `filter-delay-feedback` in the
top100 set; `filter-delay-pan`, `-levels`, `-routing` in the remaining set; `filter-delay-time-jump` in the third set, rendered by Live 12.4.7: Measured › Third set), 120 BPM, delay 2 alone (Pan centre, Volume 0 dB, Dry off), filter and feedback off
unless stated; the other two delays off. Delay times and the filter response are read from the
impulse response (65536-point FFT for the response). These are observations, not a model.

### Time

| Setting | Delay measured (centre of the impulse) | Value stored in the set |
|---|---|---|
| Time 1 ms (default) | 0.9985 ms | 1 ms |
| Time 10 ms | 9.9987 ms | 9.9964 ms |
| Time 100 ms | 100.028 ms | 100.030 ms |
| Time 500 ms | 500.000 ms | 500 ms |
| Time 999 ms | 999.002 ms | 999 ms |
| Sync button 1 | 125.000 ms | |
| Sync button 3 | 375.000 ms | |
| Sync button 5 | 625.000 ms | |
| Sync button 8 | 1000.000 ms | |
| Button 4 (500 ms), swing +33.3 % | 666.50 ms | 0.333 |
| Button 4, swing -33.3 % | 333.50 ms | -0.333 |
| Button 4, swing +16.7 % | 583.25 ms | 0.1665 |

- The delay is the set value within 0.003 ms in every case, with no fixed latency: 1 ms is 44 samples
  [measured 12.4.6]. The 10 ms and 100 ms values in the set are the nearest ones the control can store (9.996 and 100.03 ms)
  [measured 12.4.6]. Left and right are identical.
- Buttons give n x 125 ms at 120 BPM, i.e. n sixteenth notes [measured 12.4.6].
- Swing multiplies the whole synced delay by (1 + swing): 500 ms x 1.333 = 666.5 ms and
  500 ms x 0.667 = 333.5 ms, not a shift of one sixteenth (which would be 41.6 ms) [measured 12.4.6]. The requested +16.7 % became 16.65 % when stored,
  and 500 ms x 1.1665 = 583.25 ms [measured 12.4.6].
- The level of the wet path is unity: the samples of the impulse sum to 0.9998 in every case
  [measured 12.4.6].
- Fractional delays are read with a smoothing interpolator that spreads the impulse over several samples: at a half-sample
  delay (375 ms) the weights around the peak are -0.158, 0.616, 0.616, -0.158 and 0.055, and at a whole-sample delay
  (500 ms) they are -0.029, 0.041, 0.950, 0.048, -0.032 (so the interpolator
  also smooths whole-sample delays). The response is flat to 10 kHz and falls
  off above that: -0.05 dB at 12.5 kHz, -0.5 dB at 16 kHz and -2.1 dB at 20 kHz for a whole-sample delay;
  -0.85 dB, -2.7 dB and -7.5 dB at 16, 18 and 20 kHz for a half-sample delay (125 and 375 ms)
  [measured 12.4.6].

### Filter

Wet path of delay 2 at 1 ms, Feedback 0, impulse response. Levels in dB against the model below.

| Freq, Width | Low corner (-3 dB) | High corner (-3 dB) | Peak level |
|---|---|---|---|
| 449 Hz, 4 (default) | 112 Hz | 1.79 kHz | -0.03 dB |
| 1 kHz, 0.5 | none (peak is -3.5 dB) | none | -3.52 dB at 1 kHz |
| 1 kHz, 4 | 250 Hz | 3.99 kHz | -0.03 dB |
| 1 kHz, 9 | 50.1 Hz | 17.4 kHz | 0.00 dB |
| 100 Hz, 4 | 50.1 Hz | 399 Hz | -0.14 dB |
| 10 kHz, 4 | 2.50 kHz | 17.4 kHz | -0.03 dB |
| 50 Hz, 1 | none (peak is -3.5 dB at 59 Hz) | none | -3.53 dB |

- The response is Delay's: the product of two 2nd-order Butterworth sections (bilinear transform), a
  high-pass at `Freq / 2^(Width/2)` and a low-pass at `Freq x 2^(Width/2)`, each corner clamped to
  50 Hz to 18 kHz. The measured response equals this model within 0.02 dB at 31.5 Hz to 8 kHz in all seven cases;
  above 12.5 kHz the extra loss is the delay line's own roll-off, which the filter-off case shows (-0.56 dB at 16 kHz,
  -2.37 dB at 20 kHz for this 1 ms delay) [measured 12.4.6] (see Measured › Time).
- Width is the number of octaves between the corners: Width 4 at 1 kHz gives 250 Hz and 4 kHz (two octaves either side), 0.5 gives
  a narrow band whose peak is 3.5 dB below unity; Width 9 is wide open between the 50 Hz and 18 kHz limits [measured 12.4.6].
- The same limits as in Delay: the low corner never goes below 50 Hz (at 100 Hz, Width 4 the high-pass
  stays at 50 Hz and the low-pass is at 400 Hz) [measured 12.4.6].
- Filter off: flat to 10 kHz (see Time for the roll-off above that) [measured 12.4.6].

### Feedback

Delay 100.03 ms, filter off, impulse. The signed sum of the samples of each repeat (its level at low frequencies):

| Feedback | Repeat 1 | 2 | 3 | 4 | 5 | 10 |
|---|---|---|---|---|---|---|
| 25 % | +1.000 | -0.250 | +0.0625 | -0.0156 | +0.0039 | -0.0000 |
| 50 % | +1.000 | -0.500 | +0.250 | -0.125 | +0.0625 | -0.0020 |
| 75 % | +1.000 | -0.750 | +0.562 | -0.422 | +0.316 | -0.075 |
| 100 % | +1.000 | -1.000 | +1.000 | -1.000 | +1.000 | -1.000 |

- Each repeat has the opposite sign to the one before: the feedback path inverts the signal
  [measured 12.4.6]. The manual says nothing about this. The magnitude at low frequencies is the
  percentage to the displayed precision [measured 12.4.6].
- The repeats are 4412.35 samples apart (100.053 ms), one sample more than the first echo (4411.24 samples = 100.028 ms): the feedback path adds one
  sample of delay per pass [measured 12.4.6]. The n-th repeat is therefore at the delay + (n - 1) x (delay + 1 sample).
- The energy falls more than the sum at high frequencies because the interpolator smooths each pass:
  at 50 % the energy step per repeat is -6.36 dB at the first and settles to -6.05 dB (the pure -6.02 dB plus the
  roll-off); at 100 % it is -0.34 dB at the first and -0.03 dB by the twelfth (the 12th repeat is at -1.9 dB against the input). At 100 %
  nothing runs away in 19 repeats [measured 12.4.6].
- Left and right are identical here [measured 12.4.6].
- Filter in the loop: with the filter at 1 kHz, Width 4 (corners 250 Hz and 4 kHz), 50 % Feedback, the spectrum of each
  repeat falls from the one before by -6.1 dB at 1 kHz, -9.0 dB at 250 Hz and 4 kHz and -22 dB at 100 Hz: the 6.02 dB
  of the feedback plus the filter's own response again (-3.0 dB at its corners) [measured 12.4.6]. The repeat is therefore filtered
  once more on every pass, as the manual says. The first echo arrives about 0.05 ms later with the filter on (100.07 ms) [measured 12.4.6].

### Pan, Volume, Dry and routing

120 BPM, delay 2 alone (Pan centre) or as stated, a 1 kHz tone one side at a time (`filter-delay-pan`, `-levels`, `-routing`) [measured 12.4.6]:

| Case | L to L | L to R | R to L | R to R |
|---|---|---|---|---|
| Delay 2, Pan C | -6.0 dB | -6.0 | -6.0 | -6.0 |
| Delay 2, Pan 50L | -3.0 | none (-150) | -3.0 | none |
| Delay 2, Pan 25L | -3.7 | -11.4 | -3.7 | -11.4 |
| Delay 2, Pan 25R | -11.4 | -3.7 | -11.4 | -3.7 |
| Delay 2, Pan 50R | none | -3.0 | none | -3.0 |
| Delay 1 only, Pan C | -3.0 | -3.0 | none (-228) | none |
| Delay 3 only, Pan C | none | none | -3.0 | -3.0 |

- **Pan is an equal-power sine and cosine law**: with p from -1 (50L) to +1 (50R) and the angle (p + 1) x 45 degrees, the gains are 0.707 x cos and 0.707 x sin of the angle on the left and right of a sum that is itself (L + R) / 1.414; 25L reads -3.7 dB and -11.4 dB (0.652 and 0.269 against the formula's 0.653 and 0.271), L² + R² is constant at the centre, 25L and the extremes. At the centre each side carries -3 dB relative to the extreme [measured 12.4.6].
- **Delay 2 takes the sum of the two inputs** (a one-sided tone comes out on both sides at 0.5, and the impulse is 0.934 on both): the sum is (L + R) / 1.414 [measured 12.4.6]. **Delay 1 takes only the left input and Delay 3 only the right** (their other-side responses are -228 dB), each then panned: at Pan C a left-only tone is -3.0 dB on both outputs from Delay 1 and nothing from Delay 3 [measured 12.4.6].
- **Volume and Dry are exact dB gains**: Volume +6, -20 and -inf give +6.0, -20.0 dB and silence at every level from -60 to 0 dBFS, and Dry 0 and -20 dB (Delay off) give 0.0 and -20.0 dB; no distortion (0.0 % THD) [measured 12.4.6].
- The pan impulse is at 1.00 ms for the 1 ms delay (the default time), 0.934 at Pan C, 1.321 at 50L (0.934 x 1.414), so the full-pan peak is 2.4 dB above the input [measured 12.4.6].

### Third set (Live 12.4.7)

`filter-delay-time-jump` (delay 2 alone, the steady 1 kHz tone, Time Delay stepped from 100.03 ms to 199.82 ms at 23.000 s by a lane; the stored `DelayTransitionMode` 1 and 0) [measured 12.4.7]:

| `DelayTransitionMode` | what the tone does after the step |
|---|---|
| 1 (the loaded value) | no pitch change (the frequency stays 999 to 1006 Hz); the level dips to 0.199 from 0.251 (-2.0 dB) for about 25 ms (23.015 to 23.040 s): a short crossfade |
| 0 | the pitch falls from 981 Hz to 641 Hz at about 23.10 s and climbs back (684 Hz at 23.06, 728 Hz at 23.20, 826 Hz at 23.30, 923 Hz at 23.40 s); the delay has changed by 95.3 ms of the 100 ms by 0.5 s after the step; no level change |

- **Mode 1 is a crossfade and mode 0 a pitch-gliding repitch** (like Delay's Fade and Repitch, with a long glide for mode 0: the pitch error is still 8 % half a second after the step). The tone is 100 cycles of 1 kHz apart, so the crossfade shows only as a 2 dB dip from the small phase difference of the two delays (100.03 and 199.82 ms) [measured 12.4.7].
- The tone ends 200 ms later in both modes (28.949 s against the input's 28.75 s), so the new time is reached in each [measured 12.4.7].

## Implementation notes

- **Building blocks:** a biquad band-pass with the bandwidth in octaves, or a paired high-pass
  and low-pass; parameter smoothing; dB conversions.
- **Also needed:** a fractional delay line (with at least 300 ms, preferably more), a note-value
  table (the same sixteenth-button list as Delay 29.11 and Grain Delay 29.22), the X-Y pad UI
  mapping (centre and width to cutoffs).
- Share the delay line, button list and swing-offset code with Delay (29.11) and Grain Delay
  (29.22); the legacy devices are one family [source: 2].
- **.als element name:** `FilterDelay` [als 12.4.6]. Parameter elements in the set saved from Live 12.4.6
  [als 12.4.6], each holding a `Manual` value, with N = 1 – 3: `On` (bool), `OnN` (delay on, bool),
  `FilterOnN`, `MidFreqN` (Hz), `BandWidthN`, `DelayTimeSwitchN` (bool, sync), `BeatDelayEnumN`
  (index 0 – 7 into 1, 2, 3, 4, 5, 6, 8, 16), `BeatDelayOffsetN` (0 by default; a fraction: +33.3 % is stored as 0.333 [measured 12.4.6]), `DelayTimeN` (ms), `FeedbackN` (fraction, 0.21 = 21 %), `PanN`
  (−1 – 1), `VolumeN` (linear gain, 1 = 0 dB; 1.585 = 4 dB, 0.631 = −4 dB, 1.995 = 6 dB), and
  `DryVolume` (linear gain, 0.562 = −5 dB).
- The manual describes no LFO or modulation for this device, so there is none to build.
