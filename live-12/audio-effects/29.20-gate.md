# Gate (manual 29.20)

**Family:** dynamics
**Note status:** dump checked, partly measured (top100 runs, [Measured](#measured))

## Summary

A downward expander with a floor: when the detector level is under the threshold, the gain is brought down to the Floor value, and when it is over, the signal passes. Hysteresis (Return), Hold, Attack, Release and a short Lookahead keep it from chattering or clicking. It cleans noise between sounds, shortens tails, and, with the side-chain, imposes the rhythm of one signal onto another. Flip reverses it, so the device passes only quiet signals (a ducker).

## Signal flow

Shared parts: [common.md](common.md) (side-chain section).

```text
input ─┬────────────► lookahead delay (0 / 1 / 10 ms) [manual] ─► gain element ─► output
       │                                                              ▲
       └─► detector input = own input, or external side-chain × Gain blended by side-chain Dry/Wet [manual]
             └─► side-chain EQ (optional) [manual]
                   └─► level detector (type: [measure])
                         └─► open/close logic: open at Threshold, close at Threshold − Return, Flip inverts [manual]
                               └─► hold timer, then attack (closed → open) and release (open → closed) toward Floor [manual]
```

- There is no dry/wet, no output gain and no ratio or knee on this device [source: 2].
- The detector is ahead of the lookahead delay, so the gate can open before the delayed transient arrives [manual: lookahead reasoning; inferred for the tap].

## Behaviour

**Open and close levels.** The gate opens when the detector level rises over Threshold, and it closes when the level falls under Threshold − Return [manual] [inferred: hysteresis form]. With Return 0 dB, a single threshold [inferred]. A source describes Return as moving the gate-on threshold below the gate-off one [source: 2]; the manual has the pairing as "difference between the level that opens and the level that closes", which is the same quantity. I read it as open = Threshold, close = Threshold − Return [inferred] [measure] (it could also be open = Threshold + something, depending on which line the display calls Threshold). Measured at Return 0: the gate opens for a sine whose peak is above Threshold and stays closed at equality (Measured › Open level and Floor) [measured 12.4.6]; the closing level for Return above 0 was not in these runs.

**State machine.** Closed → (level over open threshold) → opening for Attack time → open. Open → (level under close threshold) → Hold period → closing over Release time → closed [manual]. Measured: Attack and Release are one-pole time constants (63 % of the change in the Attack or Release time), and the closing began 28 ms after a 24 dB drop of the input with Hold at 1 ms (Measured › Attack and Release) [measured 12.4.6]. A re-trigger during release goes back to Attack from the current gain [inferred] [measure]. Hold: a competing description ("the minimum time the gate stays closed") exists in a Sound On Sound article; the manual's description (starts when the level drops under the threshold) is used here [manual] [source: 2] conflict.

**Floor.** The gain when closed is Floor (in dB) [manual]. Opening and closing move the gain between Floor and 0 dB. Measured: the closed gain is exactly Floor (-24, -12, -6, 0 dB and -inf) and the open gain exactly 0 dB; with Floor -inf the Attack and Release curves are exponentials in the linear gain, 1 - exp(-t / Attack) and exp(-t / Release), so Release falls in a straight line in dB (Measured › Attack and Release) [measured 12.4.6]. Whether the closing curve aims at Floor or at zero gain and is cut at Floor is [measure] (the Floor-above-minus-inf cases were not run with bursts).

**Flip.** The signal passes only when the level is under the threshold [manual]. In Flip, Release is the speed at which the flipped signal rises when gating starts, and Attack the speed at which it falls when gating ends [source: 2] (so Attack and Release keep their meaning for the inverse gain, [inferred]). With Floor at −inf, a normal gate and a flipped one with identical settings, in parallel, sum to the input [source: 2] — this shows that the two gains are complementary, so the sum is exact [inferred] [measure].

**Lookahead.** Delays the audio by 0, 1 or 10 ms [manual]; the panel and the API show the middle step as 1.5 ms [dump 12.4.6], which fits the 1.5 ms (72-sample) figure below. The device reports latency equal to the lookahead [source: 5, second-hand]. The Live help centre page also lists a fixed latency figure for the Gate (72 samples, 1.5 ms) that may belong to an older version; it is second-hand and [measure].

**Detector.** The manual does not say whether it is peak or RMS. Measured: it compares a sine's peak with Threshold (first open step 3 dB above it), reacts to a rise in under 0.3 ms, takes about 28 ms to let go after a 24 dB drop, and does not open on the isolated peaks of noise 5 dB under Threshold (Measured › Open level and Floor, Attack and Release) [measured 12.4.6]; the form is a fast-attack, slow-release peak follower [inferred] [measure]. Stereo: one detector for both channels so the image does not shift [inferred] [measure].

**Display.** Input in light grey, output in dark grey with a white outline; the threshold line is blue and the Return line is orange [manual]. In Listen mode the side-chain signal is drawn in green [manual].

**Side-chain.** As in [common.md](common.md). Used for rhythmic gating: a held pad opened by a drum loop [manual].

## Edge cases

- Floor 0 dB: the device does nothing to the signal [manual].
- Floor −inf: a closed gate is silent [manual].
- Threshold at its minimum: the gate is always open (without Flip); with Flip always closed [inferred].
- Hold 0 and Return 0 with a signal at the threshold: chatter [source: 4]; Return and Hold reduce it [manual].
- Attack minimum with a Floor of −inf: the gain steps from silence to full level in less than a cycle of low frequencies: clicks [manual].
- Lookahead 0 with a fast transient and a slow Attack: the transient's start is attenuated [inferred].
- Changing Lookahead while playing: changes delay; the host's delay compensation changes [source: 5] [inferred]; clicks [measure].
- Flip with Floor at −inf: complementary to the normal gate [source: 2].
- Mono input, silence (the gate is closed or stays in its state), denormals: [measure].

## Measured

[measured 12.4.6] Behaviour runs at 44.1 kHz in Live 12.4.6 (`measurements/29.20-gate/`:
`gate-threshold-floor`, `gate-attack-release`, in the top100 set). Fixed settings unless stated:
Threshold -18 dB, Return 0, Attack 0.02 ms, Hold 1 ms, Release 0.1 ms, Floor -inf, Lookahead 0, Normal,
no side-chain. The open/closed state is read from the 1 kHz staircase (rising in 3 dB steps, 0.25 s
each; levels are the sine's peak dBFS), and the opening and closing from the bursts (-30, -6, -30
dBFS, 1 s each; the -6 dBFS burst opens the gate at 1.0 s, the following -30 dBFS burst closes it at
2.0 s) through the 0.25 ms envelope of the gain. These are observations, not a model.

### Open level and Floor

| Threshold | Steps closed (dBFS) | First open step |
|---|---|---|
| -45 dB | up to -45 | -42 |
| -33 dB | up to -33 | -30 |
| -21 dB | up to -21 | -18 |
| -9 dB | up to -9 | -6 |

- **The gate opens at the first step above Threshold.** A sine whose peak equals Threshold stays
  closed and one 3 dB higher passes, at every Threshold tried (Return 0), with 3 dB resolution
  [measured 12.4.6]. If the detector read the sine's RMS level (3 dB under its peak), the step 3 dB above
  Threshold would sit exactly at Threshold, a marginal case; a reading near the peak fits more
  simply [inferred]. A staircase in 1 dB steps would settle it.
- **Open means exactly unity.** The gain of an open gate was 0.00 dB with 0.0 % THD at every level
  [measured 12.4.6]; there is no ratio or knee.
- **Closed means Floor exactly, at every level.** Floor -24, -12 and -6 dB gave a gain of -24.00,
  -12.00 and -6.00 dB at each closed step from -60 dBFS; Floor 0 dB changed nothing; Floor -inf gave
  digital silence (-240 dB). The closed gain does not depend on the input level [measured 12.4.6].
- **The detector does not follow single peaks.** With Threshold -9 dB, the probe's noise (-18 dBFS RMS,
  peaks to -3.9 dBFS) never opened the gate in 4 s, while a -6 dBFS sine did. With Threshold -21 and -33 dB the
  noise passed [measured 12.4.6]. A peak detector with no smoothing would have opened on the
  noise's peaks above -9 dBFS; the detector therefore smooths the level over at least a few samples
  [inferred].

### Attack and Release

Attack (Release 0.1 ms; the gate opens for the -6 dBFS burst after a closed -30 dBFS burst); the
gain is read on a linear scale:

| Attack | Fitted time constant of 1 - gain | Time to 63 % | Time to 90 % |
|---|---|---|---|
| 0.02 ms | under the 0.25 ms resolution | 0.5 ms | 1.0 ms |
| 1 ms | 1.06 ms | 1.5 ms | 2.7 ms |
| 10 ms | 10.0 ms | 10.5 ms | 23.4 ms |
| 50 ms | 50.0 ms | 50.1 ms | 115 ms |
| 150 ms | 145 ms | 147 ms | 334 ms |

Release (Attack 0.02 ms; the gate closes for the -30 dBFS burst after the -6 dBFS one):

| Release | Fitted time constant | Gain change per second | Fall starts after the burst ends |
|---|---|---|---|
| 10 ms | 10.0 ms | -869 dB/s | 28.0 ms |
| 50 ms | 50.0 ms | -174 dB/s | 28.0 ms |
| 200 ms | 200.0 ms | -43.4 dB/s | 28.0 ms |
| 500 ms | 500 ms | -17.4 dB/s | 28.0 ms |

- **Attack and Release are time constants of a one-pole smoother of the linear gain.** The opening
  follows 1 - exp(-t / Attack) and the closing exp(-t / Release), with a fitted time constant equal to
  the knob within 1 % for Attack 10 and 50 ms and Release 10 to 500 ms (Attack 1 ms fits 1.06 ms, at the
  envelope's resolution; Attack 150 ms fits 145 ms). The 63 % time is the knob value, and the
  90 % time is 2.3 times it [measured 12.4.6]. The gain therefore falls in a straight line in dB, 8.69
  dB per Release time, and never "finishes": with Floor -inf it keeps falling to digital
  silence (-207 dB in the envelope) instead of stopping at a fixed depth. The manual's wording "time to
  close" is a time constant, not the time to reach the floor [inferred].
- **Opening starts at once, closing starts 28 ms late.** The gain starts to rise within 0.3 ms of the
  burst's start, but the fall begins 28.0 ms after the burst's end for every Release from 10 to 500 ms.
  Here the burst is 12 dB over Threshold and the next one 12 dB under it, with Hold at its minimum
  of 1 ms, so the 28 ms is mostly the detector's decay, not Hold [measured 12.4.6] [inferred for the cause].
  The detector rises fast and falls with a time constant of the order of 20 ms, like a peak follower
  with a release [inferred]; how the delay depends on the level drop is [measure].
- (`analyse.py`'s t63 and t90 for these cases, 30 ms to 0.8 s, measure the 207 dB range down to silence and
  are not the knob times; the fits above use the linear gain.)

2. **Open and close levels.** A sine whose level ramps slowly up and then down (0.5 dB/s) across the threshold with Attack and Release minimum, Hold 0, Floor −inf, Lookahead 0. Record the levels at which the gate opens and closes with Return 0, 6, 12 dB and the maximum; compare with Threshold and Threshold − Return. Check the display lines against the measured levels.
   Partly: Return 0 only, on the rising staircase (3 dB resolution): the gate opens at the first step above Threshold (Measured › Open level and Floor). Still open: the closing level for Return 6, 12 and the maximum (the `gate-return` run is not in the top100 set), the display lines, and the slow ramp.
3. **Floor and gain law.** Closed gate with Floor −inf, −12, −6, 0: read the output level; read the attenuation curve of a release from open to closed (output / input) with Release 100 ms and 1 s: linear in dB? exponential?
   Done for Floor -24, -12, -6, 0 and -inf (the closed gain is exactly Floor, at every level) and for the release curve at Release 10, 50, 200 and 500 ms with Floor -inf: an exponential in the linear gain, a straight line in dB (Measured › Open level and Floor, Attack and Release). Release 1 s and a finite Floor with bursts were not run.
4. **Attack and Release times.** A tone burst over the threshold with a long silence between: read the gate's opening (Attack 0.1, 1, 10, 100 ms) and closing (Release 10, 100, 1000 ms), from the ratio of output to input; report 10 %–90 % and 63 % times.
   Done for Attack 1, 10, 50 and 150 ms and Release 10, 50, 200 and 500 ms: the 63 % time equals the knob; the 90 % time is 2.3 times it (Measured › Attack and Release). Attack 0.1 ms and a Release of 1 s were not run.
5. **Hold.** A burst followed by a drop under the threshold; Hold 0, 50, 200, 1000 ms with Release minimum: measure the time between the level drop and the start of the gain fall; check against the manual's definition, and against the "stays closed" reading by re-triggering bursts at a short interval.
6. **Re-trigger during release.** Two bursts separated by less than Release; check the gain curve of the second attack (restart from the current gain or from the floor).
7. **Flip.** Repeat tests 2, 3 and 4 with Flip on; check which of Attack and Release applies to which transition; run the parallel normal-plus-flipped null test with Floor −inf (expected: sum = input).
8. **Lookahead and latency.** Impulses at Lookahead 0, 1, 10 ms; read the delay at 44.1 and 48 kHz; compare with the title bar's tooltip; check that the transient passes at full level when Attack is minimal. Look for any latency when Lookahead is 0 (the help centre's 72-sample figure).
9. **Detector type.** Tone bursts of 0.5, 1, 5, 20 ms with the same peak level around the threshold: does the open decision depend on the burst length (RMS) or only the peak? Test with a signal with a high crest factor (an impulse train).
10. **Stereo.** One channel loud, the other silent; different levels per channel; check the gain applied to the silent channel.
11. **Side-chain.** External source, Gain range, Dry/Wet 0 / 50 / 100 %, EQ filter types, frequency, Q and gain ranges (noise through each, Listen on), as for Compressor; check the display colour in Listen mode.
12. **Sample rates.** Repeat test 4 at 44.1, 48 and 96 kHz.

## Implementation notes

- **Building blocks:** biquad filters for the side-chain EQ, one-pole envelopes, dB conversions.
- **Also needed:** a hysteresis state machine with hold, a fixed lookahead delay that reports its latency, a peak detector and a level display.
- If the detector is shared with Compressor and Glue Compressor, one detector (peak, RMS, side-chain filter) can serve all three.
- The key input is the same side-chain primitive Compressor uses ([common.md](common.md) › Side-chain section).
- `.als` import: the element is `Gate` [als 12.4.6]. Parameter elements in the set saved from Live 12.4.6 [als 12.4.6], each holding a `Manual` value: `On` (bool), `Threshold` (linear gain, 0.251 = −12 dB), `Attack` (ms), `Hold` (ms), `Release` (ms), `Return` (dB), `Gain` (this is the Floor, in dB: −40), `SideChain/OnOff` (bool), `SideChain/RoutedInput/Volume` (linear gain, the side-chain Gain), `SideChain/DryWet` (fraction), `SideListen` (bool), `SideChainEq/On` (bool), `SideChainEq/Mode` (index 0 – 5, the type list above), `SideChainEq/Freq` (Hz), `SideChainEq/Q`, `SideChainEq/Gain` (dB), `FlipMode` (0 Normal, 1 Flip) and `LookAhead` (index 0 – 2 into 0, 1.5, 10 ms; the loaded value is 1). The stored units are therefore physical (ms, dB) except the two linear-gain fields.
