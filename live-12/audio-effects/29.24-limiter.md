# Limiter (manual 29.24)

**Family:** dynamics
**Note status:** dump checked, partly measured (top100 runs, [Measured](#measured))

## Summary

A lookahead peak limiter for the Main track (or anywhere a hard ceiling is needed). It keeps the output under a Ceiling, can be switched to a "maximizer" form in which one Threshold control both limits and raises the loudness, and has a Release with an Auto mode, a stereo Link amount, left/right or mid/side routing, three lookahead times and three ceiling modes (Standard, Soft Clip, True Peak). Live 12.1 rebuilt it in sound and appearance [source: 2]; this note describes the 12.1 and later device.

## Signal flow

Shared parts: [common.md](common.md) (none of the side-chain section: this device has no side-chain).

```text
input ─► Input Gain (Gain) ─► [M/S encode if Routing = M/S] ─► lookahead delay (1.5 / 3 / 6 ms)
                                    │                                  │
                                    └─► peak detector ─► gain computer vs Ceiling (or Threshold in Maximize)
                                          ─► release envelope (Release or Auto) ─► Link between the two channels
                                                │                                  ▼
                                                └──────────────────────────► gain element
 ─► [soft clip if Ceiling Mode = Soft Clip] ─► [true-peak handling if True Peak] ─► [M/S decode] ─► output
GR meter shows the gain reduction; level meters show the output.
```

- Maximize: the Ceiling control becomes Threshold, the Input Gain control becomes Output; lowering Threshold adds makeup gain equal to the Threshold cut, so the loudness rises as the dynamic range falls [manual].
- With Routing = M/S, the signal is converted to mid/side before the limiter stage and back at the output; this costs more latency [manual].
- A limiter is a compressor with an infinite ratio [manual].

## Behaviour

**Basic action.** Peaks above the ceiling are reduced so the output does not pass it; with no peaks over the ceiling, no limiting [manual]. The reduction is done with a lookahead of 1.5, 3 or 6 ms; the lookahead acts as the attack time [manual]. Measured (Standard, L/R, Lookahead 3 ms): the output equals the input plus Gain up to the Ceiling and sits exactly on the Ceiling above it, with no knee, no overshoot (the sample peak was at the Ceiling to 0.001 dB) and 0.0 % THD for a steady sine; the gain falls smoothly over the 3 ms before a loud burst (Measured › Ceiling, Gain and Maximize, Lookahead and Release) [measured 12.4.6].

**Gain and Ceiling.** Gain raises or lowers the level before the limiter [manual], so raising it with a fixed Ceiling means more limiting [inferred].

**Maximize.** Ceiling becomes Threshold; makeup gain equal to the Threshold cut is added (Threshold −6 dB gives +6 dB of makeup) [manual]; the Gain knob becomes Output and sets the target level [manual]. Measured: the makeup is exactly −Threshold, the limiter then holds the signal at 0 dBFS, and Output is a gain applied after the limiter, so Output is the true ceiling (Threshold −6 dB, Output −6 dB: gain 0.00 dB, limit −6.00 dBFS) (Measured › Ceiling, Gain and Maximize) [measured 12.4.6]. The Max object lists `output` as the "target maximum output level" [source: 3].

**Release and Auto.** The new envelope gives smoother releases, especially with long release times [source: 2]. Auto selects the release time from the signal [manual]; no rule is documented, the usual one is a program-dependent release made of a fast and a slow time [inferred] [measure]. Measured: the release is a one-pole in the linear gain with a time constant equal to the knob (10 ms to 1 s within 0.2 %); after a 1 s burst limited by 12 dB, Auto released as one exponential with a time constant of 220 ms (Measured › Lookahead and Release) [measured 12.4.6]; the dependence on duration and amount is [measure].

**Link.** A continuous parameter in both L/R and M/S routings since 12.1 [source: 2]. With link, the gain reduction used for each channel is a mix of the channel's own and the other channel's: `gr_used = gr_own + link × (max(gr_L, gr_R) − gr_own)` is one candidate [inferred] [measure]. At 0 % the channels are independent and the stereo image may "wobble" [manual].

**Routing.** L/R: two independent (or linked) channel limiters. M/S: the limiting is done on the mid and side signals, so mono and stereo content can be limited independently [source: 2]; extra latency [manual].

**Ceiling modes.** Standard: plain lookahead limiting [manual]; in Standard the sample peaks stay under the ceiling but inter-sample peaks may not, since True Peak exists to prevent them [inferred]. Soft Clip: a soft clipper near the ceiling, adds colour and punch, an LED flashes when clipping happens [manual]; shape [measure]. True Peak: keeps the inter-sample (reconstructed) peaks under the ceiling [manual]; probably by oversampling the detector or the whole path (the latency changes, [inferred] [measure]).

**Latency.** Equal to the lookahead (1.5, 3 or 6 ms) and more in M/S mode [manual]. The help centre lists a fixed 128 samples (2.7 ms) figure for an older Limiter (second-hand via a search summary), which is outdated for 12.1 [source: 4] [measure].

**Order with other devices.** The manual advises putting the Limiter last on the Main track and keeping the track's volume under 0 dB, since later processing can add gain [manual].

## Edge cases

- Input under the ceiling: no gain change, but the signal is delayed by the lookahead [manual] [inferred]; in Maximize mode the signal is raised even with no limiting [manual].
- Ceiling at 0 dB with True Peak off: sample peaks never pass 0 dBFS [manual] [inferred]; inter-sample peaks can [manual].
- Release very short with low-frequency content: distortion; the lookahead choice matters most for bass [manual].
- Link 0 % on mono-compatible material: channel-dependent gain, a wobbling image [manual].
- Switching Lookahead, Routing or Ceiling Mode while playing changes latency and, possibly, the output; clicks [measure].
- Soft Clip with a hot input: LED flashing [manual].
- Silence, denormals, sample rates (the lookahead is in ms, so the delay in samples changes) [inferred] [measure].
- Mono input with M/S routing: the side channel is empty; only mid is limited [inferred].

## Measured

[measured 12.4.6] Behaviour runs at 44.1 kHz in Live 12.4.6 (`measurements/29.24-limiter/`:
`limiter-static`, `limiter-maximize`, `limiter-release`, in the top100 set). Base settings: Gain 0,
Ceiling -6 dB, Release 100 ms (Auto off), Link 100 %, Lookahead 3 ms, Standard, L/R, Maximize off. The
probe only reaches 0 dBFS, so the limiter is driven with Gain (+12 and +24 dB). Output levels are
the fundamental of the 1 kHz staircase (3 dB steps, 0.25 s) and, for the release, the ratio of the
output to the input envelope over the bursts (-30, -6, -30 dBFS, 1 s each) at 0.25 ms. Live
compensates the Limiter's delay when it renders, so the lookahead does not show as a delay in the
files. These are observations, not a model.

### Ceiling, Gain and Maximize

- **A hard ceiling with no knee.** Output level = input + Gain up to the Ceiling and the Ceiling above it,
  to 0.01 dB at every 3 dB step: Gain +12 and Ceiling -6 dB gave -48 dBFS for a -60 dBFS input, -9 dBFS for
  -21, and -6.00 dBFS for every step from -18 to 0; Gain +24 reached -6.00 at -30; Ceiling -12 and -1 dB
  gave -12.00 and -1.00 dBFS flat. The sample peak of the limited sine was at the Ceiling to 0.001 dB, the
  THD 0.0 % in the limited steps, and in the bursts the peak of the limited burst was -6.000 dBFS in the first
  5 ms as in the last: no overshoot and no undershoot [measured 12.4.6].
- **Gain is a pre-gain.** Gain -12 dB with Ceiling -1 dB gave output = input - 12 dB at every level, never
  limited (input 0 dBFS -> -12 dBFS) [measured 12.4.6].
- **Maximize adds exactly -Threshold as gain, then limits at 0 dBFS, then applies Output.** With Output 0
  dB and a sine under the threshold the gain was +3.00, +6.00, +12.00 and +24.00 dB for Threshold -3, -6,
  -12 and -24 dB, and the output stopped at 0.00 dBFS in all four. The default Threshold (-0.3 dB) gave +0.30
  dB. Threshold -6 dB with Output -6 dB gave a gain of 0.00 dB and a limit at -6.00 dBFS; Threshold -12 dB with
  Output -12.375 dB gave a gain of -0.38 dB (+12 - 12.375) and a limit at -12.38 dBFS. So Output is a gain
  after the limiter, and the limiter itself sits at 0 dBFS; the manual's "Threshold -6 dB gives +6 dB of
  makeup" is exact [measured 12.4.6].
- **The case named "Output -12 dB" used -12.375 dB** (the harness stored -12.375, a value inside the
  display's two significant digits; the Remote Script read back the same value), so its figures are
  those of Output -12.375 dB. The Ceiling and Threshold values of -12 dB were stored as -12 dB and came out as
  exactly -12.00 dB [measured 12.4.6].

### Lookahead and Release

Release, Gain +12, Ceiling -6 dB, Lookahead 3 ms; the -6 dBFS burst is limited by 12 dB. The gain
recovers as a one-pole in the linear gain: 1 - gain/(unlimited gain) = 0.75 x exp(-t / tau).

| Release | Fitted tau |
|---|---|
| 1 ms | 1.2 ms (envelope resolution 0.25 ms) |
| 10 ms | 10.02 ms |
| 100 ms | 99.98 ms |
| 300 ms | 299.99 ms |
| 1000 ms | 1001 ms |

- **Release is the time constant of a one-pole smoother of the linear gain** (the fitted tau equals the
  knob from 10 ms to 1 s within 0.2 %). The 63 % time is the knob value and the 90 % time is 2.3 times it.
  In dB the recovery is a curve, not a line: at Release 100 ms the reduction left was 11.8 dB (of 12) 2 ms
  after the burst, 5.4 dB after 50 ms, 2.8 dB after 100 ms and 0.9 dB after 200 ms [measured 12.4.6].
  It starts at once: there is no hold.
- **Lookahead acts as the attack.** After the delay compensation the gain falls from +12 to 0 dB in the
  3 ms before the loud burst starts, smoothly: 0.1 dB of the 12 dB is gone 2.8 ms before the burst,
  0.6 dB at 2.3 ms, 1.9 dB at 1.8 ms, 4.2 dB at 1.3 ms, 7.5 dB at 0.8 ms and all of it when the burst
  starts. The 3 ms lookahead is the whole attack [measured 12.4.6]. The other lookaheads were not
  in these runs.
- **Auto.** After a 1 s burst limited by 12 dB the gain recovered as one exponential in the linear
  gain with a time constant of 220 ms (219 to 223 ms between 2 and 800 ms, fit within 0.3 %), slower than the
  Release knob's 100 ms [measured 12.4.6]. Whether the time depends on the duration or the amount of the
  limiting (a fast and a slow stage are claimed) was not measured here: only one burst was run.
- (`analyse.py`'s attack and release figures for these cases are not used here: the gain it reads
  is the pre-gain-plus-limiting ratio, and the recovery is not a single step in dB.)

## Implementation notes

The core is the textbook lookahead limiter: a delay line of the lookahead length, a sliding minimum of the required gain over the window, a moving-average smoothing of that gain so it reaches its value as the peak arrives, then a release (a one-pole time constant), with the gain linked across channels (the max of the two sides) and a latency equal to the lookahead.

What Live 12.1+ adds on top of that core:

- **Gain** (−24 to +24 dB) before limiting, and **Maximize**, which changes Ceiling to Threshold and Gain to Output (a pre-gain equals a threshold of −Gain with the ceiling fixed) [dump 12.4.6].
- **Ceiling** from −24 to 0 dB [dump 12.4.6].
- **Link** (0 – 100 %): a per-channel gain blended towards the linked one.
- **Auto** release; selectable **Lookahead** (1.5, 3, 6 ms), so the delay line and the sliding minimum take their length from a parameter and the reported latency changes with it.
- **Ceiling Mode** Standard, Soft Clip and True Peak (8× or 4× oversampled detection); **Routing Mode** L/R or M/S; the level meters.

Building blocks: one-pole smoothing, dB conversions, oversampling (for the true-peak detector); no biquads are needed.

`.als` import: the element is `Limiter` [als 12.4.6]. Parameter elements in the set saved from Live 12.4.6 [als 12.4.6], each holding a `Manual` value: `On` (bool), `Gain` (dB, the Input Gain), `Ceiling` (dB), `Release` (ms), `AutoRelease` (bool), `LinkAmount` (fraction), `LinkAmountMidSide` (fraction), `Lookahead` (index 0 – 2 into 1.5, 3, 6 ms), `Routing` (0 L/R, 1 M/S), `Mode` (0 Standard, 1 Soft Clip, 2 True Peak), `Maximize` (bool), `MaximizeThreshold` (dB, −0.3) and `MaximizeOutput` (dB). Gain and levels are therefore stored in dB, not linear gain. Sets saved before 12.1 hold the older, smaller parameter set; how they map is [measure] on a saved older set.
