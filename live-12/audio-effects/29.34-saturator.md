# Saturator (manual 29.34)

**Family:** distortion
**Note status:** dump checked, partly measured (top100 and remaining runs, [Measured](#measured))

## Summary

Saturator is a waveshaper: it maps every sample through a curve chosen from eight, after a Drive
gain, with optional frequency-dependent saturation (the Color filters), a post-clip stage, an Output
level and Dry/Wet [manual]. The Waveshaper curve opens a set of extra controls for building a custom
curve. Live 12.1 redesigned the device around its main controls and added the Bass Shaper curve, a
hard-clip choice for the post stage, a live level display on the curve and the Color curve display
[source: 3]. Used from a light warm-up on a bus to extreme folding on a synth.

## Signal flow

```text
input ─► [Pre-DC Filter, optional] ─► Color filters (EQ curve) ─► Drive ─► Curve ─► inverse Color filters ─► Post Clip ─► Output ─► Dry/Wet ─► out
          [manual]                     [manual]                   [manual] [manual]  [manual]              [manual]    [manual]  [manual]
 └──────────────────────────────────────────────────────────────────────────────────────────────────────────► dry (input) ──────────────────┘
```

- Drive is "before the signal is processed" [manual]; the order of Drive and the first Color filter
  is [measure] (the manual says the EQ curve is applied before the shaper, so the Color filter
  precedes the curve either way).
- The Color filters are applied "before the shaper, then again, inverted, after the shaper" [manual]. The net
  linear response is flat; only the saturation amount per band changes [manual].
- Soft Clip adds an instance of the Analog Clip curve at the output; Hard Clip clips hard [manual]. Both limit the
  output to the Output level [manual]. Whether Soft Clip is before or after Output gain is [measure]; the
  manual says output "never exceeds the level set by the Output control", which means the clip follows the
  Output attenuation or the clip's ceiling is the Output setting [inferred].
- The Max wrapper has `drive` (-36 – +36 dB), `gain` (output, -70.6 – 0 dB), `mix`, `dcblock`, `oversample` and `post_clip` (No Clip, Soft Clip, Hard Clip) [source: 4].

## Behaviour

**Gain and curve.** `y = shape(drive · x)` for the fixed curves, per sample and per channel [inferred]. Drive at -36 dB attenuates; the curves have unity slope at the origin so that low levels are about unchanged [inferred, "remain linear below the clipping point" for the clip curves: manual]. Per type:

| Curve | What the manual and sources say | Likely structure [inferred] |
|---|---|---|
| Analog Clip | linear below the clip point, smooth transition around it, "cut off completely" above [source: 4] | exactly linear (error below -120 dB) up to 0.708, rounded from there (0.90 at 1.0, 0.98 at 1.41), flat at 1.000 from about 2 [measured 12.4.6] (Measured › Curves) |
| Digital Clip | immediate hard clipping at the clip point | `clamp(x, -1, 1)`: unity slope, no distortion at an amplitude of 1.0, clipped above [measured 12.4.6] (Measured › Curves) |
| Soft Sine | saturation with its own character (softer than the clips) | `sin(π/2 · clamp(x, -1, 1))`: matches the render to 0.01 up to 1, then flat at 1 [measured 12.4.6] (Measured › Curves) |
| Medium Curve | saturation, between soft sine and hard curve | not tanh-like: slope 2.000 at the origin and exactly flat at 1.000 from about 0.65 input on, like Analog Clip with twice the input gain [measured 12.4.6] (Measured › Curves) |
| Hard Curve | saturation, closer to a hard clip | slope about 6.8 at the origin and rounded from the smallest levels (0.54 at 0.1, 0.75 at 0.2, 0.93 at 0.5, 1.0 from about 1) [measured 12.4.6] (Measured › Curves) |
| Sinoid Fold | wavefolder; louder input folds back | `sin(π/2 · x)` unclamped: 1.0 at 1, 0.02 at 2, -1.0 at 3, 0 at 4 [measured 12.4.6] (Measured › Curves) |
| Bass Shaper | like Analog Clip, but smoother harmonic spectrum on loud low frequencies; linear below the threshold, smooth clip above | at the default Threshold (-50 dB) slope 1 at the origin, then `1 - exp(-x)` within 0.01 up to 4 (0.39 at 0.5, 0.63 at 1, 0.87 at 2) [measured 12.4.6]; other thresholds not rendered |
| Waveshaper | user-shaped; see below | polynomial plus superimposed sine |

The linear-below-the-clip-point statement applies to Analog Clip and Digital Clip only [manual]. The clip point is 0 dBFS (amplitude 1.0) after Drive for Digital Clip, and Analog Clip stays exactly linear up to 0.708 (-3 dBFS) after Drive [measured 12.4.6] (Measured › Curves). All six fixed curves are odd-symmetric: no even harmonic above -105 dB [measured 12.4.6].

**Waveshaper.** Six parameters feed a transfer function. Likely composition: a base polynomial (Curve adds third-order terms, Linear sets the slope of the straight part), `+ Depth · sin(2π · Period · x)` (Depth amplitude, Period ripple count), and Damp zeroing a small region around the origin (a dead zone, "ultra-fast noise gate" [manual]) [inferred]. Shaper Drive crossfades between the plain linear curve (0 %) and the shaped curve (100 %) [manual], [source: 4b]. The output level of the Waveshaper (set by Drive and Output) can exceed full scale; the Post Clip Mode catches it [inferred].

**Color filters.** Two filters whose summed EQ curve is shown on the display. The shaper sees `EQ(x)`; the output is `EQ⁻¹(shaper(EQ(x)))`, so with an EQ that boosts a band by +6 dB before the curve, the band is saturated more, and the output boost is removed [manual]. Amt Lo: gain of the first filter for low frequencies (low shelf [inferred]); Amt Hi: gain of the second (bell) filter at Frequency with Width [manual]. The inverse filter has the inverse gain [manual]; its realisation (a second filter set with negated gain) is [inferred]. The net linear response is flat: with Amt Lo +100 % (+36 dB) and Amt Hi +100 % (+24 dB) and a curve that stays linear, the response is flat within ±0.005 dB from 25 Hz to 20 kHz and the phase is that of Color off, so the inverse is exact [measured 12.4.6] (Measured › Color). The manual's own use case: cut bass before the shaper so that only mids and highs saturate, while the bass energy is retained [manual].

**Post Clip.** Soft Clip adds an Analog Clip curve on the output, Hard Clip a hard clipper; the output never exceeds the Output level [manual]. Useful for the extra level that negative Color values create [manual].

**Hi-Quality and DC.** Hi-Quality oversampling reduces aliasing; the renders have it on (the loaded state). The linear response is flat in magnitude to 20 kHz (within 0.005 dB) and the phase departs from zero only above about 5 kHz (group delay 0.1 sample at 5 kHz, 0.6 at 10 kHz, 2 at 15 kHz, 8 at 20 kHz), so there is no latency in the audio band [measured 12.4.6] (Measured › Linear path); the factor is [measure] (the Max wrapper has an on/off `oversample` attribute [source: 4]). Pre-DC filter is a DC-blocking high-pass at the input [manual]; the cutoff is [measure] (typically 5 – 20 Hz [inferred]). The Max object has a `dcblock` option [source: 4].

**Stereo.** Both channels process with the same curve [inferred]; the Waveshaper is not described as stereo-different.

**Display.** The curve with the live input level (since 12.1) [source: 3]. The Shaper Curve display shows the composite of Drive and curve [manual].

## Edge cases

- **Drive at -36 dB with a linear curve:** unchanged but quiet; with Output at 0 dB the signal is attenuated [inferred].
- **Drive +36 dB:** the curve operates as a hard limiter; aliasing without Hi-Quality [inferred].
- **Bass Shaper threshold at 0 dB:** acts as a hard clip, at -50 dB as a soft clip [manual].
- **Waveshaper with Shaper Drive 0 %:** the other five controls have no effect [manual].
- **Color on with Amt Lo / Amt Hi at 0:** no effect: the sweep through Digital Clip at Drive +12.4 dB reads the same 12.3 dB at every frequency as the curve alone predicts [measured 12.4.6].
- **Soft Clip with negative Color values:** the extra boost is clipped to the Output level [manual].
- **DC offset in the input:** Pre-DC Filter removes it before the curve; without it an asymmetric curve produces extra harmonics [manual], [inferred].
- **Silence:** Waveshaper with a damping region gives silence for small signals [manual].
- **Old sets:** sets from Live 6 with Saturator load again without "corrupt document" warnings after 12.1.11 and 12.2 fixes; older sets keep their old curves [source: 3].
- **Latency:** none reported in the manual. Measured with Hi-Quality on: zero delay below 5 kHz and a flat magnitude, with group delay growing to 8 samples at 20 kHz; the dry path of Dry/Wet is not delayed [measured 12.4.6] (Measured › Linear path). With Hi-Quality off [measure].

## Measured

[measured 12.4.6] Behaviour runs at 44.1 kHz in Live 12.4.6 (`measurements/29.34-saturator/`: `saturator-curves`, `saturator-drive-output-mix`, `saturator-color` in the top100 set; `saturator-waveshaper`, `-bass-shaper`, `-postclip`, `-predc` in the remaining set; `saturator-curves-ramp`, `-color-more`, `-hiquality`, `-hiquality-types`, `-predc-step`, `-waveshaper-more` in the third set, rendered by Live 12.4.7: Measured › Third set), Color off (except in the Color run), Post Clip No Clip, Output 0 dB, Dry/Wet 100 %, Hi-Quality on (the loaded state; it is not an API parameter and was never switched), curve Analog Clip unless a case says otherwise. Levels come from the staircase (1 kHz sine, -60 to 0 dBFS in 3 dB steps; the analysis "gain" is the rms of the whole output times the square root of 2, so it includes the harmonics) and from reading the output against the probe sample by sample, with the input multiplied by Drive (called u below: the amplitude that reaches the curve, 1.0 = full scale). Color is read from the -12 dBFS sweep. These are observations, not a model.

### Things that affect how to read the renders

- **Drive and Output "display" values were stored on a 1/64 grid of the range** (1.125 dB for Drive, 0.5625 dB for Output): the cases named Drive -12, +12 and +30 dB, and Output -12 dB, stored -12.375, +12.375, +30.375 and -12.375 dB (Drive 0, 18 and 36 dB and Output 0 and -36 dB are exact), and the Color run's Drive "+12" and the linear check's Drive "-24" stored 12.375 and -23.625 dB. The renders read these stored values (Measured › Drive, Output, Dry/Wet). [measured 12.4.6]
- **No two cases of these runs are bit-identical** apart from the bypass renders (checked with md5); the `default` case of `saturator-drive-output-mix` is the `default` render of `saturator-curves` (same settings, one track). [measured 12.4.6]
- **High Drive overshoots 1.0.** With the clip curves at u = 7.9 the output peak reaches 1.12 (Analog Clip), 1.15 (Digital Clip) and 1.37 (Hard Curve): a ring from the oversampling filter, not a higher clip level. [measured 12.4.6]

- **Drive is linear in dB and nothing else:** the gain below the knee equals the stored value to 0.01 dB, and gain and THD at any input level depend only on input level plus Drive (Drive +36 at -36 dBFS gives the same -0.447 dB and THD 3.97 % as Drive 0 at 0 dBFS; Drive +12.375 and +30.375 differ by exactly 18 dB and give identical gain and THD rows 18 dB apart in input level) [measured 12.4.6]. - **Output** at -12.375 and -36 dB moves the whole curve by the stored dB: small-signal gain 5.62 and -18.00 dB at Drive 18, and the saturated output at 0 dBFS in 2.74 - 12.38 = -9.63 dBFS and -33.26 dBFS. Without post clip it is a gain after the curve, no clipping of its own [measured 12.4.6].
- **Dry/Wet 50 %** (Drive 18, Analog Clip): the output equals 0.5 x input + 0.5 x the 100 % wet render to within -150 dB, for the sweep, noise, staircase, steady sine and impulse. So it is an equal-gain linear crossfade, the dry signal is the unprocessed input (no Drive, no Output) and is time-aligned with the wet signal. At -60 dBFS in the gain is 13.01 dB = 20 log(0.5 + 0.5 x 7.94) [measured 12.4.6].

### Color

Digital Clip, Drive +12.375 dB, the -12 dBFS sweep (the sine reaches u = 1.04 with Color flat) (`saturator-color`). With the Color filters flat the sweep reads +12.3 dB at every frequency. A filter that boosts a band before the curve pushes the sine further into the clip, and the fundamental that comes back is lower than the linear gain: for a sine of amplitude A at the curve a clip returns a fundamental of F(A), and the sweep's gain is the Drive gain times F(A)/A. Solving that for the boost in front of the curve gives each filter's gain against frequency (assuming the inverse filter after the curve is exact, which the linear check below supports). 3. **Waveshaper.** Ramp with every Waveshaper parameter alone at 0, 25, 50, 75, 100 % and Shaper Drive at 100 %; read polynomial coefficients, the added sine's amplitude and ripple count versus Depth and Period, the dead zone of Damp; Shaper Drive at 0, 50, 100 % to read the crossfade law.
   Partly: Linear (gain), Curve (a quadratic term), Damp, Depth, Period and Shaper Drive at one or two settings each by staircase (Measured › Waveshaper). Intermediate values, polynomial coefficients beyond the quadratic term and the DC behaviour are open.
   More: Curve 25, 75, 100 %, Depth 25 and 75 % at Period 50 %, Damp 25 and 75 %, Linear 0 and 100 %, Shaper Drive 0 and 50 % (Measured › Third set): Curve is proportional to a quadratic term, Depth adds slope as its square, Shaper Drive is a linear crossfade. The DC behaviour is still open.
4. **Drive and Output taper.** 1 kHz sine at -30 dBFS: confirm the gain for Drive at -36, -18, 0, 18, 36 dB and for Output (displayed ranges and tapers are linear in dB per the dump [dump 12.4.6]). Read Dry/Wet at 50 % for equal-gain or equal-power.
   Done: Drive and Output are exactly linear in dB (Drive -12.4 to +36 dB, Output -12.4 and -36 dB, read to 0.01 dB; Drive -36 and -18 dB not rendered), Dry/Wet 50 % is 0.5 x dry + 0.5 x wet, an equal-gain crossfade (Measured › Drive, Output, Dry/Wet).
5. **Color filters.** Linear check: sine sweep at -40 dBFS with Drive 0 dB and a curve that is linear at that level (Analog Clip): response should be flat with Color on at any Amt Lo / Amt Hi. Saturation check: sine sweep at about -6 dBFS with Digital Clip; with Amt Lo and Amt Hi at -100, 0, +100 % and several Frequency and Width settings, read the level of the third harmonic against frequency, which shows where saturation is raised or lowered; match it to the Color Curve display (centre, width, gain). (Ranges and defaults of Amt Lo, Amt Hi, Frequency and Width are in the dump [dump 12.4.6].)
   Partly: the linear check passes (flat within ±0.005 dB, Measured › Color). The saturation check was read from the fundamental of the sweep through Digital Clip, not the 3rd harmonic: Amt Lo +100 % (a low shelf of +36 dB), Amt Hi +100 % at 1 kHz (Width 30 % and 0 %) and at 200 Hz (Width 100 %) give the filters' gains, centre and width; the negative amounts, other Frequencies and intermediate amounts were not rendered, and the negative side shows only as raised low-frequency distortion products.
   More: Amt Hi +50 % at 200 Hz and 5 kHz (a half-gain bell of the same shape) and the negative amounts again unreadable through Digital Clip (Measured › Third set).
6. **Post Clip.** Drive +24 dB, Output at -6 dB and 0 dB: check the output peak for No Clip, Soft Clip, Hard Clip; check whether the Soft Clip is before or after the Output gain.
   Done: Hard Clip is a clamp at 1.0 before Output, Soft Clip is 0.6 + 0.4 tanh((x - 0.6) / 0.4) before Output (Measured › Post Clip).
7. **Hi-Quality.** 10 kHz sine at Drive +24 dB with Hi-Quality on and off: read the alias products to estimate the oversampling factor; impulse response for latency.
   Partly: latency and the linear path read from the existing renders (no delay in the audio band, a phase turn above 5 kHz; Measured › Linear path). Hi-Quality off and the oversampling factor were not rendered in those runs: the setting is not an API parameter (the third set stores it as an element, which works: Measured › Third set).
   Done in the third set (stored Oversampling element): the lines of 10 and 15 kHz sines at Drive +24 dB for Analog Clip, Digital Clip, Sinoid Fold and the Waveshaper; on is 4x oversampling (Measured › Third set).
8. **Pre-DC Filter.** Sine with +0.3 DC offset: read the output DC and the filter's cutoff (step response).
   Response done (a pair of one-pole high-passes at 27 Hz, Measured › Pre-DC Filter); the step response with a DC offset was not rendered (the probe has none).
   Done: the step response and the 1, 5 and 20 Hz sines match two one-pole high-passes at 27 Hz (Measured › Third set).
9. **Defaults.** Settled by the dump [dump 12.4.6] and the saved set [als 12.4.6]; Hi-Quality is not a dump parameter; its default (on) comes from a plain value in the saved set [als 12.4.6].

## Implementation notes

- **Building blocks:** static curves (a hard clip for Digital Clip, tanh as a base for Medium/Hard Curve; extend with Analog Clip, Soft Sine, sine fold, Bass Shaper and the waveshaper function); oversampling (Hi-Quality: two times or more; measure the factor); a DC blocker (Pre-DC Filter); biquad low shelf and peak for the Color filters (the inverse filter is the same filter with the gain negated); parameter smoothing for Drive and Output; dB conversions.
- **Also needed:** the curve set; the Waveshaper function; Bass Shaper with threshold; a post-clip stage; the Color curve display data (the EQ's magnitude response); a live level display (input peak levels sent to the UI).
- **Hard to match:** the curve shapes (measure), Color filter ranges and the first filter's type, Hi-Quality oversampling, post clip ordering.
- **Related:** Overdrive (29.27) shares the path structure (filters, oversampler, DC blocker, dry-path delay for the latency) but not much else: Saturator needs Drive of ±36 dB, eight curves, Color, post-clip and a different mix.
- **`.als` element:** `Saturator` [dump 12.4.6]. Parameter elements [als 12.4.6] (stored units where they differ from the display): `On`, `PreDrive` (Drive, dB, 0), `PreDcFilter`, `Type` (index, 0 = Analog Clip), `ColorOn`, `BaseDrive` (Amt Lo, 0), `ColorFrequency` (Hz), `ColorWidth` (0.3 = 30 %), `ColorDepth` (Amt Hi, 0), `PostClip` (0 = No Clip), `PostDrive` (Output, dB, 0), `DryWet` (1 = 100 %), `BassShaperThreshold` (dB, −50), `WsDrive` (1), `WsLin` (0.5), `WsCurve` (0.05), `WsDamp`, `WsPeriod`, `WsDepth`. Hi-Quality is not a parameter but a plain value, `Oversampling` (true) [als 12.4.6]. The element names `BaseDrive` and `ColorDepth` echo the older names Base and Depth. Old sets (Live 6 and later) load a Saturator with the older parameter names (Base, Frequency, Width, Depth) [source: 6]; mapping from them is [measure].
