# Overdrive (manual 29.27)

**Family:** distortion
**Note status:** dump checked, partly measured (top100 and remaining runs, [Measured](#measured))

## Summary

Overdrive is a classic pedal-style distortion that keeps dynamic range even when driven hard. A
band-pass filter (set on an X-Y pad) selects what is distorted, Drive sets the amount, Tone shapes
the result, Dynamics sets how much compression and make-up the drive brings with it, and Dry/Wet
mixes in the original [manual].

## Signal flow

```text
input ─► band-pass (Frequency, Bandwidth) ─► distortion (Drive) with built-in compression (Dynamics) ─► Tone ─► Dry/Wet ─► out
          [manual]                           [manual]                                                 [manual]  [manual]
 └──────────────────────────────────────────────────────────────────────────────────────────────────────────► dry ───────┘
```

- The band-pass comes before the distortion [manual].
- Whether the band-pass also affects what remains of the dry signal (the dry is the unfiltered input) is [inferred]: dry is the device input.
- SOS: with Dry/Wet at 0 % Tone still affects the signal [source: 2]. That suggests Tone (or part of it) sits after the mix, or applies to the dry path too [measure]. Measured in 12.4.6: at Dry/Wet 0 % the output is bit-identical to the bypass for Tone 0 % and 100 %, so Tone sits in the wet path only, and the dry path is not delayed relative to the bypass after Live's delay compensation [measured 12.4.6] (Measured › Tone).
- Where Dynamics' compression sits (before, inside or after the distorting stage) is [measure].

## Behaviour

- **Band-pass and drive.** The signal outside the band is attenuated before the curve, so the saturation only sees the selected range [manual]. The bandwidth is a width in octaves, with edges at Frequency x 2^(+/-Bandwidth/2) and skirts of about 12 dB per octave, except that the narrowest setting (0.5) is wider than that [inferred from the measurement] (Measured › Band). The band-pass is probably a pair of high- and low-pass filters, or a band-pass biquad [inferred].
- **Distortion.** A soft, asymmetric-capable curve in the style of a pedal; the manual says heavy drive still keeps the dynamics intact [manual]. This is only possible with some level control that stops the output rising with drive [inferred].
- **Dynamics.** Measured: at Dynamics 0 % the curve is a static clipper that saturates near 0 dBFS output; at 100 % the output does not saturate (+7.7 dBFS out for 0 dBFS in) and distortion starts 18 dB lower in input level (Measured › Drive and Dynamics) [measured 12.4.6]. With Dynamics low, rising Drive increases the internal compression and make-up gain; with Dynamics high, less compression is applied [manual]. SOS reads the same: high settings give almost no compression as Drive rises, low settings heavy compression [source: 2]. The implementation may be a gain computer that follows the input level and a make-up gain linked to Drive [inferred].
- **Tone.** A tilt, shelving or low-pass EQ after the distortion [manual]. SOS describes it as post-distortion high-pass filtering and says it runs from deep bass to harsh noise at extremes, especially with Drive at maximum [source: 2], which conflicts with the manual's "more high-frequency content at higher values" only in wording; it is probably a shelf or tilt with its centre at mid frequencies [inferred]; type and corner: a tilt with a plateau of +3 dB above 1 kHz at 100 % and a fall of about 6 dB per octave above 250 Hz at 0 %; the corner is near 300 to 500 Hz (Measured › Tone) [measured 12.4.6].
- **Dry/Wet.** Linear [inferred]. SOS notes that Tone still acts at Dry/Wet 0 % [source: 2]; in 12.4.6 it does not (bit-identical to the bypass) [measured 12.4.6].

## Edge cases

- **Drive 0 %:** still distorts [manual].
- **Dynamics at either end with Drive high:** at 0 % heavy compression, at 100 % none [manual], [source: 2]. Output level changes with Drive: at Dynamics 100 % the small-signal gain rises 0.36 dB per percent and the loud end converges to +7.7 dB gain; at 0 % the output is capped near -0.1 to -0.3 dBFS [measured 12.4.6] (Measured › Drive and Dynamics).
- **Narrow band:** the distorted signal is only the narrow band; at Dry/Wet 100 % the rest of the spectrum is attenuated [inferred].
- **Silence:** silent; a DC blocker may remove offset from asymmetry [inferred].
- **Latency:** none documented; oversampling inside would add latency [measure].

### Drive and Dynamics

Gain is the output level minus the input level of the 1 kHz sine, and "out" the output level in dBFS, both as the step's rms times the square root of 2, so the harmonics are included (above 0 dBFS the float render is not clipped) [measured 12.4.6]:

| Drive 0 %, Dynamics 100 % | -3.25 dB | -39.3 / -21.2 / -3.3 dBFS | 0.2 / 9.5 / 13.6 / 13.7 % | -43, -21 |
| Drive 25 % | +5.75 dB | -30.4 / -12.7 / +4.8 | 0.5 / 10 / 14 / 14 % | |
| Drive 50 % | +14.75 dB | -22.3 / -8.2 / +7.6 | 1.5 / 19 / 18 / 19 % | -29, -18.5 |
| Drive 75 % | +23.7 dB | -18.9 / -8.1 / +7.7 | 4.7 / 33 / 20 / 20 % | |
| Drive 100 % | +32.5 dB | -18.3 / -8.1 / +7.7 | 22 / 36 / 20.5 / 20.5 % | -49, -17.6 |
| Drive 50 %, Dynamics 0 % | +14.75 dB | -21.3 / -4.3 / -0.3 | 0.2 / 1.5 / 21 / 40 % | -19.5, -15 |
| Drive 100 %, Dynamics 0 % | +32.75 dB | -4.3 / -0.3 / -0.1 | 1.5 / 21 / 42 / 42 % | -36, -9.7 |

- **Drive is gain into the curve, linear in dB:** the small-signal gain is -3.25 dB at 0 % and rises by 9.0 dB per 25 % (0.36 dB per percent) to +32.75 dB at 100 %, 36 dB in all [measured 12.4.6]. With Dynamics 0 % the curves of Drive 50 % and 100 % are the same curve shifted by exactly 18 dB of input level (same gain and THD at levels 18 dB apart) [measured 12.4.6].
- **Drive 0 % still distorts:** the output level keeps its gain of -3.25 dB at every level (the distortion takes under 2 % of the power), but from -24 dBFS in it carries 3rd and 5th harmonics at about -21 and -22 dB (13.6 % THD, 9.5 % at -30 dBFS) that do not change with level up to 0 dBFS. So at Drive 0 % the output is a fixed-shape distortion added at a constant relative level, not a saturating curve [measured 12.4.6] [inferred: a level-normalised clipper, see Dynamics].
- **Dynamics 0 %: a static soft clipper.** Output rises 1:1 with input until the knee (-24 dBFS in at Drive 50 %: gain 14.5 dB), then flattens at about -0.3 dBFS (-0.28 at 0 dBFS in, Drive 50 %; -0.14 at Drive 100 %); the first harmonic is the 2nd (-67 dB at -60 dBFS, -30 at -24), the 3rd takes over above the knee (-10 dB at 0 dBFS in), THD 40 to 42 % when saturated [measured 12.4.6].
- **Dynamics 100 %: the output does not saturate.** The same drive curve bends at the same input levels, but beyond it the output keeps rising with input: from -24 to 0 dBFS in, about 5.3 dB out per 6 dB in at Drive 50 %. Whatever the Drive, the loud end converges: the gain at 0 dBFS in is +7.6 dB (Drive 50 %) and +7.7 dB (75 and 100 %), and at -6 dBFS +8.3 to +8.4 dB for every Drive from 50 %. The THD at high level is then constant at 18 to 20.5 % with the 3rd at -17.6 to -18.5 dB [measured 12.4.6].
- So Dynamics 100 % puts a level-dependent gain (about 7 dB less than the small-signal gain at 0 dBFS in at Drive 50 %, 25 dB less at Drive 100 %) in front of or around the clipper, so that the waveform shape stays the same and the level still follows the input; at 0 % the clipper simply clips. The THD at a given input level at Dynamics 100 % equals that of Dynamics 0 % with Drive 50 percentage points higher (18 dB): Drive 50 % at Dynamics 100 % has 0.36, 1.5 and 7.8 % THD at -60, -48 and -36 dBFS, exactly the values of Drive 100 % at Dynamics 0 %, and Drive 100 % at Dynamics 100 % is again 18 dB earlier. So Dynamics 100 % starts the distortion 18 dB lower in input level without changing the small-signal gain [measured 12.4.6] [inferred].
- Level at the output is not normalised: full-scale input gives +7.7 dBFS out at Dynamics 100 % (Drive 50 % and up) and -0.1 to -0.3 dBFS at Dynamics 0 % [measured 12.4.6].

- **The 3 kHz sine is far more distorted than the 1 kHz sine at the same Drive**, and 3rd-harmonic dominated. The 3rd harmonic (9 kHz) is 9, 9, 6, 5 and 5 dB under the fundamental at Drive 0 to 100 %; the 5th (15 kHz) 28, 27, 17, 13 and 12 dB under; the 7th (21 kHz) 39, 42, 28, 19 and 18 dB under; the 2nd (6 kHz) 36, 27, 21, 30 and 39 dB under (THD 36.6, 38.1, 51.9, 60.4 and 61.5 %). At Drive 0 % the 1 kHz sine reads 13.7 % and the 100 Hz sine 4 %. The second harmonic falls with Drive above 50 % (as at 1 kHz: -49 dB at Drive 100 %). The reason that the distortion rises so fast with frequency is not known: a shaper that is memoryless in the filtered signal would show the same harmonic ratios at any frequency, so the harmonics are shaped or the shaping depends on frequency afterwards (the Tone stage, the band-pass applied after the shaper, or the Dynamics gain) [measured 12.4.7; the candidates are inferred] [measure: the 3 kHz sine at Dynamics 0 % and Tone 0 %, and at Drive 100 % with Bandwidth 9].
- **Aliasing.** The 9th, 11th, 13th and 15th harmonics of 3 kHz fold to 17.1, 11.1, 5.1 and 0.9 kHz; they read -40, -37, -49 and -40 dB under the fundamental at Drive 0 %, -39, -44, -39 and -47 dB at 50 %, and -37, -33, -35 dB (17.1, 11.1, 5.1 kHz) at Drive 100 %. These lines are inharmonic, so the shaper (or the filter after it) is not band-limited: the stage is not band-limited above the harmonics that fold, which is what a shaper running at the base rate without oversampling does [measured 12.4.7; the absence of oversampling is inferred].

2. **Drive curve and level.** 200 Hz and 2 kHz sine from -60 to 0 dBFS in 6 dB steps, Drive at 0, 25, 50, 75, 100 %, Dynamics 0 and 100 %: output level, harmonic spectrum (odd and even), small-signal gain; gives the curve and the compression behaviour.
   Partly: 1 kHz only, 3 dB steps, Drive 0, 25, 50, 75, 100 % at Dynamics 100 % and Drive 50, 100 % at Dynamics 0 % (Measured › Drive and Dynamics). Still open: 200 Hz and 2 kHz, Dynamics 50 %.
   Also done: Dynamics 50 % at Drive 100 % (Measured › Dynamics against level and time).
   More: a 100 Hz staircase, the 1 kHz ramp and a 3 kHz sine at Drive 0 to 100 % (Measured › Third set): the band-pass sits in front of the drive curve; 200 Hz and 2 kHz as such, and Dynamics 50 % at every Drive, are still open.
3. **Dynamics.** Tone bursts alternating between -30 and -6 dBFS, Drive 100 %, Dynamics at 0, 50, 100 %: read the level difference between bursts (compression) and the make-up gain; detector attack and release from the settling times.
   Done at Dynamics 0, 50, 100 % at Drive 100 %: a memoryless level curve; the 24 dB burst step comes out as 0.9, 7.0, 20.1 dB; no attack or release at 5 ms resolution (Measured › Dynamics against level and time).
4. **Tone.** Sine sweep at -40 dBFS, Drive 0 %, Tone at 0, 25, 50, 75, 100 %: read the filter shape, corner and slope; repeat at Dry/Wet 0 % to see the SOS observation.
   Done at Tone 0, 25, 50, 75, 100 % (Drive 0 %, Bandwidth 9) and Tone 0/100 % at Dry/Wet 0 %: no effect at Dry/Wet 0 %, contradicting SOS (Measured › Tone). Corner and slope of the filter described, not fitted.
5. **Dry/Wet.** 1 kHz sine at 50 %; impulse for the dry path delay.
   Done at 0, 25, 75 % at Drive 75 %: an equal-power cosine and sine crossfade, no dry delay (Measured › Dry/Wet).
6. ~~**Defaults.**~~ Answered by the dump and the saved set [dump 12.4.6] [als 12.4.6].

## Implementation notes

- **Likely structure [inferred]:** a band (high-pass and low-pass pair) → Drive into a biased asymmetric tanh at 2x oversampling → DC blocker → Tone → Dynamics → Dry/Wet, with the dry path delayed by the oversampler's latency if there is any. Live's ranges and defaults [dump 12.4.6]: Frequency up to 20 kHz; Drive 50 %, Tone 50 %, Dynamics 50 %, Dry/Wet 50 %, 1.25 kHz, width 6.5.
- **Open points for the design:** whether Tone is a low-pass, a tilt or a shelf [measure]; Dynamics is described as a compressor link, not a level follower [manual]; whether the device reports latency (probably none) [measure]; the X-Y display for the band; the device has no Output control.
- **Building blocks:** biquad high-pass, low-pass and band-pass; an asymmetric tanh curve with a bias; oversampling; a DC blocker; one-pole smoothing.
- **Missing:** a compressor-style Dynamics stage, a Tone filter matched to the measurement, the XY display (UI).
- **`.als` element:** `Overdrive` [als 12.4.6]. Parameter elements in the set saved from Live 12.4.6 [als 12.4.6], each holding a `Manual` value: `On` (bool), `MidFreq` (Hz, 1250), `BandWidth` (6.5), `Drive` (0 – 100, stored as the percentage number: 50), `DryWet` (0 – 100: 50), `Tone` (0 – 100: 50) and `PreserveDynamics` (fraction: 0.5 = 50 %). Note that Drive, Dry/Wet and Tone are stored on a 0 – 100 scale while Dynamics is a 0..1 fraction.
