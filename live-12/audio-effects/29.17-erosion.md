# Erosion (manual 29.17)

**Family:** distortion
**Note status:** dump checked

## Summary

Erosion degrades the input by modulating the time of a very short delay with a mix of a sine wave
and band-pass-filtered noise. The result ranges from noisy artefacts to something like downsampling
distortion [manual]. The device was redesigned in Live 12.4 (Noise Blend and Stereo Width replace
older mode switches); sets saved before 12.4 load the earlier device as Erosion Legacy [manual],
[source: 2]. This note covers the 12.4 device and records the legacy controls where they differ.

## Signal flow

```text
input ─► very short delay line (time modulated) ─► out
              ▲
              │ modulation = (1 − Noise Blend)·sine(Freq) + Noise Blend·noise(band-pass: Freq, Filter Width) ; scaled by Amount
              │ Stereo Width: modulation mono (0 %) … independent in left and right (100 %)
```

- The modulated element is a short delay [manual]. How the Amount, in time units, maps is [measure].
- Erosion has no Dry/Wet control in the manual. SOS says that in the earlier device Amount mixes wet and dry: at zero only the dry signal is heard [source: 3]. Whether the 12.4 device still does so is [measure].
- Algorithmic latency is about 2 ms in 12.4, previously about 5 ms [source: 2].

## Behaviour

- **Delay modulation.** `y[n] = x[n − d[n]]` where `d` is a few samples to a few ms plus the modulation; the delay line is read with interpolation (linear or higher) [inferred]. A fast sine of a few kHz as modulation produces strong frequency-modulation sidebands, which sound like aliasing or downsampling [manual], [inferred].
- **Modulator.** `m[n] = (1−b)·sin(2π·f·t) + b·noise_bp[n]`, `b` = Noise Blend [manual], [inferred]. The noise is filtered by a band-pass at `f` with a bandwidth given by Filter Width [manual]. The sine and the noise are combined with weights (not necessarily linear in amplitude).
- **Amount.** Scales the modulation depth in time (the Y axis) [manual].
- **Stereo Width.** At 0 % one modulator (mono) is used for both channels; at 100 % independent modulators for the two channels (as the old Wide Noise); in between the two are mixed [manual], [inferred]. It applies to the sine too: phase offset between the channels [inferred]; SOS reports that Wide Noise used separate delay lines for left and right [source: 3].
- **Display.** The spectrum of the input and the modulation graphic [manual]. The filter-width animation is a visual aid [source: 2].
- **Filter Width disabled** when Noise Blend = 0 % [manual].
- **Not a bitcrusher.** CDM: Erosion is neither a downsampler nor a bit crusher like Redux [source: 2].

## Edge cases

- **Amount 0:** the modulation is zero; the output is the input delayed by the fixed base delay (about 2 ms latency reported) [inferred].
- **Noise Blend 0 %:** Filter Width has no effect and is greyed out [manual].
- **Stereo Width 0 %:** mono modulation, a mono input stays mono [inferred]; at 100 % a mono input becomes stereo [inferred].
- **Freq extremes:** very low Freq gives slow wobble (chorus or vibrato-like), very high gives aliasing-like noise [inferred].
- **Tempo, transport:** no tempo sync; the modulation oscillator free-runs [inferred].
- **Latency:** about 2 ms in 12.4 [source: 2]; compensated by Live [inferred].
- **Old sets:** load as Erosion Legacy [manual].

## Measurement plan

1. **Delay time and latency.** Impulse at Amount 0 %, 12.4 device: read the output delay; compare to 2 ms. Repeat with Erosion Legacy (about 5 ms).
2. **Amount law.** 1 kHz sine at Noise Blend 0 %, Freq 500 Hz and 5 kHz, Amount at 0, 25, 50, 75, 100 %: read the FM sideband spacing and the modulation index to get the delay excursion (in samples or ms) against Amount; check the taper.
3. ~~**Freq range and defaults.**~~ Answered by the dump (Freq 20 Hz – 18 kHz, logarithmic, default 500 Hz; all other defaults too) [dump 12.4.6]. What unit Filter Width is in (octaves?) remains [measure].
4. **Noise.** Noise Blend 100 %, input a sine: read the sideband spectrum against Freq and Filter Width (centre, bandwidth, units, the range of Filter Width); check the noise type (white filtered by a band-pass); check repetition.
5. **Blend.** Noise Blend 0, 25, 50, 75, 100 %: read the sine and noise contributions' amplitudes to see the mixing law.
6. **Stereo Width.** Mono sine into both channels; Stereo Width 0, 50, 100 %: correlation between left and right outputs; for the sine, any phase offset.
7. **Dry/Wet question.** Amount 0 compared to bypass to check if the device mixes dry and wet; at 50 % Amount compare with the formula.
8. **Alt-drag.** Check that Alt-Y drag edits Filter Width and what the vertical range maps to.

## Implementation notes

- **Building blocks:** a sine oscillator, a biquad band-pass with the bandwidth in octaves (noise filter), one-pole parameter smoothing.
- **Also needed:** a fractional delay line with interpolation (shared with chorus, flanger and Roar's feedback); a noise generator (white or similar, seeded per channel); a modulation mix with Noise Blend; a stereo-width mix of two modulators; the XY display.
- **Hard to match:** exact modulation depth in time; the base delay and interpolation type (these determine the sound); the stereo morph.
- **Related:** Vinyl Distortion (29.41) needs a seeded noise generator for its crackle; the two can share it.
- **`.als` element:** `Erosion2` for the 12.4 device [als 12.4.6]; old sets map to Erosion Legacy, whose element name is [measure]. Parameter elements in the set saved from Live 12.4.6 [als 12.4.6], each holding a `Manual` value: `On` (bool), `Amount` (fraction, 0.2 = 20 %), `Frequency` (Hz, 500), `FilterWidth` (1.0), `NoiseBlend` (fraction, 0.5) and `StereoWidth` (fraction, 0.25). So percentages are stored as 0..1 fractions and Frequency in Hz.
